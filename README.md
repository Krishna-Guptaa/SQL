## 📌 Project Overview

This project demonstrates SQL-based analysis on a Supply Chain dataset. It contains real-world business questions along with optimized SQL solutions to extract meaningful insights that support data-driven decision-making.

## 🎯 Objectives

- Analyze supply chain operations using SQL
- Solve real-world business problems
- Improve query writing and optimization skills
- Generate actionable business insights

## 🛠️ Technologies Used

- MySQL
- SQL
- Joins
- Aggregate Functions
- GROUP BY & HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- CASE Statements
